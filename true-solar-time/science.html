◈ 核心公式(与代码一一对应)

JD = Unix毫秒/86400000 + 2440587.5;T = (JD − 2451545.0)/36525(儒略世纪数)
L₀ = 280.46646° + 36000.76983°T + 0.0003032°T²(太阳平黄经)
M = 357.52911° + 35999.05029°T − 0.0001537°T²(平近点角)
C = 1.914602°sinM + 0.019993°sin2M + 0.000289°sin3M(中心差)
λ = L₀ + C − 0.00569° − 0.00478°sinΩ(视黄经,含光行差与章动)
ε = 23°26′21.448″ − 46.815″T + Δε(真黄赤交角)
α = atan2(cosε·sinλ, cosλ),δ = asin(sinε·sinλ)(视赤经/赤纬)
EoT = L₀ − 0.0057183° − α + Δψ·cosε,分钟 = 度 × 4
真太阳时 = 北京时 + (经度 − 120°)×4分 + EoT
cosH₀ = [sin(−0.833°) − sinφ·sinδ]/[cosφ·cosδ];日出/落(北京时) = 720 − (经度−120°)×4 − EoT ∓ H₀×4

◈ 问答

Q1 为何不用简化EoT拟合公式? 网传 B=2π(N−81)/364、EoT=9.87sin2B−7.53cosB−1.5sinB 拟合误差可达30秒,且未计时差的长期项。本站逐时刻解算视赤经,含章动,误差<8秒。
Q2 日出落为何与天气App差几十秒? 三项来源:①对方多用简化算法;②对方经度取市中心与本站市政府坐标差几公里;③高程与山体遮挡未建模(拉萨、乌鲁木齐山区可差1–3分钟)。平原城市应<1分钟。
Q3 节气按黄经还是按日? 天文节气是时刻(黄经整数点),本站 sun.html 节气表取该时刻所在北京时间日期的日出落,与“某日交节”民用表述一致,黄经列给出整数度供核验。
Q4 子午流注为何必须用真太阳? 《灵枢》以日出日入为开阖,经脉流注锚定太阳时角。全国统一北京时后,西部同一挂钟时刻太阳时角差可达45°,即3个时辰,经脉完全错位。
Q5 如何复算? 打开 astro.js,任意时刻 ASTRO.sunApparent(new Date()) 即得 λ/α/δ/EoT,与美国海军天文台 MICA 或紫金山年历对拍正午即可。
